## Summary

The official COVESA project landing page for Diagnostic Log and Trace (DLT). It describes DLT as a standardized logging and tracing protocol for automotive ECUs, standardized in AUTOSAR, and hosted/maintained as an open-source project under COVESA. Serves as the authoritative high-level entry point that ties the protocol standard (AUTOSAR) to the reference implementation (COVESA `dlt-daemon`).

## Key Concepts

- DLT is a **standardized logging and tracing protocol**, standardized in **AUTOSAR**.
- Maintained by **COVESA** (Connected Vehicle Systems Alliance, formerly GENIVI) as an open-source project.
- The reference implementation is the `dlt-daemon` project (daemon + `libdlt` library + client tools such as DLT Viewer).
- Positioned for automotive/embedded systems to collect logs and traces from applications and basic software on an ECU and forward them to diagnostic clients.

## Details

The project page situates DLT within the broader COVESA ecosystem and points to the implementation and community resources. For the concrete protocol format and behaviour, it defers to:

- The **AUTOSAR** Diagnostic Log and Trace specifications (protocol requirements + software specification).
- The **COVESA `dlt-daemon`** repository and its documentation for the reference implementation, tooling and developer guides.
