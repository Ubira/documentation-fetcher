## Summary

Official IEEE Standards Association record for **IEEE Std 1003.1-2024**, the *IEEE/Open Group Standard for Information Technology — Portable Operating System Interface (POSIX) Base Specifications, Issue 8*. POSIX.1-2024 is simultaneously IEEE Std 1003.1-2024 and The Open Group Standard Base Specifications, Issue 8. The page provides authoritative status, history, and working-group metadata (the full text is purchase/subscription only from IEEE).

## Key Concepts

- **Status:** Active Standard.
- **Board Approval:** 2024-05-20. **Published:** 2024-06-14.
- **Supersedes:** IEEE Std 1003.1-2017.
- **Proposed Corrigendum:** P1003.1-2024/Cor 1 — first technical corrigendum, scoped to correct accidental deviations from other standards and industry practice, and to allow publication as **ISO/IEC/IEEE IS 9945**.
- POSIX.1-2024 comprises the same four volumes: Base Definitions, System Interfaces, Shell and Utilities, and Rationale (Informative).
