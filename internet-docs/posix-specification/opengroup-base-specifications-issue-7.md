## Summary

The freely readable HTML edition of **POSIX.1-2017**, published simultaneously as **IEEE Std 1003.1-2017** (a revision of IEEE Std 1003.1-2008) and **The Open Group Technical Standard Base Specifications, Issue 7**. This is the previous POSIX edition and remains the version most implementations, Linux man pages, and RTOS subprofiles reference. A newer edition (Issue 8 / POSIX.1-2024) now exists.

## Key Concepts

- Same four-volume structure as Issue 8:
  - **Base Definitions (XBD)**
  - **System Interfaces (XSH)**
  - **Shell and Utilities (XCU)**
  - **Rationale (XRAT, Informative)**
- Defines a standard OS interface and environment (shell + utilities) for source-code-level application portability, for both application developers and system implementors.
- Same out-of-scope list as Issue 8 (graphics, DBMS, record I/O, object/binary portability, system configuration).
