## Summary

Official IEEE Standards Association record for **IEEE Std 1003.13-2003**, the *IEEE Standard for Information Technology — Standardized Application Environment Profile (AEP) — POSIX Realtime and Embedded Application Support*. This is the standard that formally defines the realtime profiles **PSE51–PSE54**. It is part of the POSIX series of standardized profiles for open systems and defines environment profiles for portable realtime and embedded applications. Full text is purchase/subscription only.

## Key Concepts

- Defines environment profiles for portable **realtime and embedded** applications (the PSE51 Minimal, PSE52 Controller, PSE53 Dedicated, PSE54 Multi-Purpose profiles).
- **Status:** Inactive-Reserved Standard (inactivated 2021-03-25) — its intent is now carried by the subprofiling options of IEEE 1003.1-2017.
- **Supersedes:** IEEE Std 1003.13-1998.
